# Changelog

What's changed in each version. Newest first.

## 0.3.0

- **Getting started is obvious now.** Open a chat and say "set me up" and it runs your setup. No need to know the slash command.
- **Your memory is visible.** Setup ends by showing what it now knows about you, and from then on it tells you in one line whenever it saves something ("Noted in memory/..."), so memory feels like it's growing instead of filling up in the dark.
- Lighter first-session nudge that never talks over your first message.

## 0.2.0

- **New skill: improve.** Paste a link or a technique about running Claude or agents better and it tells you what's worth adopting for your setup (Adopt / Adapt / Skip), then applies it on your yes or saves it for the weekly self-improvement pass. It's the reactive counterpart to self-improvement.

## 0.1.0

- First release: setup, a memory that learns who you are and how you work, and the four workflows (morning brief, weekly prep, open loops, self-improvement), plus sync and consolidate to keep memory fresh.
